# ESA-Fanatics-Purchases-Analysis

Python analysis of Fanatics purchase and email campaign data completed as part of my Clemson Athletics Spring 2027 ESA Internship Application.

## Project Overview

This project evaluates email campaign performance, purchasing behavior, and geographic revenue patterns to identify opportunities to improve fan engagement and merchandise revenue.

## Analysis

The project uses Python and pandas to:

- Clean and prepare purchase and campaign data
- Analyze revenue by email campaign
- Evaluate promo code usage
- Compare revenue across states and geographic regions
- Identify differences in campaign performance
- Develop data-driven recommendations for improving fan engagement

## Tools

- Python
- pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data

The underlying Fanatics purchase dataset is not included in this public repository because it contains customer-level information from the original application dataset.

The notebook demonstrates the analysis methodology without including the underlying raw data.
